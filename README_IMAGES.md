## 🎨 Spécifications des images

### Logos d'équipes
- **Format** : PNG avec fond transparent
- **Dimensions** : 200x200 pixels minimum
- **Poids** : < 50 KB par image
- **Style** : Icône/symbole représentant le nom de l'équipe

### Logo principal
- **Format** : PNG avec fond transparent
- **Dimensions** : 400x400 pixels
- **Poids** : < 100 KB

### Images de fond
- **Format** : JPG ou PNG
- **Dimensions** : 1920x1080 pixels minimum
- **Poids** : < 500 KB (optimisé)
- **Qualité** : Haute résolution

## ✅ Checklist avant d'ajouter une image

- [ ] Image optimisée (taille < 100 KB si possible)
- [ ] Nom de fichier correct (sans espaces, en minuscules)
- [ ] Format correct (PNG pour logos, JPG pour photos)
- [ ] Dimensions appropriées
- [ ] Testé sur la page (F5 pour recharger)

## 🚀 Comment ajouter vos images

1. Créer le dossier s'il n'existe pas :
```bash
mkdir -p frontend/assets/images/equipes
```

2. Copier vos images :
```bash
cp votre_logo.png frontend/assets/images/equipes/al_furqan.png
```

3. Recharger la page dans le navigateur

## 🎨 Template de conception suggéré
